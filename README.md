# ASSU Debate Club Website

This repository contains the source code for the ASSU Debate Club website, a static website designed to provide information about the club, its events, and how to join.

## Project Structure

```
assu-debate-club-website
├── assets
│   ├── css
│   │   └── styles.css        # CSS styles for the website
│   ├── js
│   │   └── main.js           # JavaScript for interactivity
│   └── images                # Directory for images used in the website
├── .github
│   └── workflows
│       └── deploy.yml        # GitHub Actions workflow for deployment
├── index.html                # Main HTML file for the website
├── .gitignore                # Files and directories to ignore by Git
├── LICENSE                   # Licensing information for the project
└── README.md                 # Documentation for the project
```

## Getting Started

To get a local copy of the project up and running, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/assu-debate-club-website.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd assu-debate-club-website
   ```

3. **Open `index.html` in your web browser** to view the website.
